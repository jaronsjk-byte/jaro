The **Notifications** page lists reminders ChillMind has raised — upcoming scheduled items and tasks you have missed.

You can mark a single notification as read, mark everything as read at once, delete one notification, or clear the whole list. The sidebar shows a count of unread notifications.

The list is paginated. Use the page controls at the bottom to move between pages, and change how many notifications appear per page.
