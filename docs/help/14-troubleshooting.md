title: When something looks wrong
tags: [broken, error, missing, lost, blank, slow, bug]
---

If your progress has vanished, the most likely cause is a page refresh or a new session, which clears session data by design.

If a page looks blank or a control does not respond, reload the app to start a clean session.

If the Mentor replies with a short generic message, its AI service was briefly unavailable and it fell back to built-in replies. Try again in a moment.
